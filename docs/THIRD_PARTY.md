# Privacy dependency provenance

- `@hpke/core` 1.9.0 (MIT): RFC 9180 P-256 / HKDF-SHA256 / AES-256-GCM content encryption. No wallet-derived content secrets.
- `jose` 6.2.12 (MIT, [source](https://github.com/panva/jose)): official local OAuth OIDC/JWKS signature and claims verification; no decode-only identity trust.
- `eventsource-parser` 4.1.1 (MIT, [source](https://github.com/rexxars/eventsource-parser)): official Responses stream framing; completion/usage/limits remain app validation.
- `@lit-protocol/keychain` 2.2.3 (Apache-2.0): current Chipotle runtime verification. Client adds exact measurement policy, actual-connection TLS pinning and mandatory full collateral verification.
- `ipfs-unixfs-importer` 17.1.1 (Apache-2.0/MIT), esbuild 0.28.2 (MIT): immutable action build/CID calculation, not attestation.
- `contracts/vendor/risc0`: RISC Zero Ethereum v3.0.1, commit `365e7b2db4f620fa256580c27558d2623362b9ae`. Original files retained except relative SafeCast import paths. Groth16 verifier files are **GPL-3.0**; other files carry their original Apache-2.0 notices. Both license texts are included. The combined verifier/registry deployment must respect GPL-3.0 obligations; it is not an exclusively MIT contract distribution. RISC Zero soundness includes the published Groth16 setup and pinned recursion/control circuits. No mutable verifier router is used.
- `contracts/vendor/openzeppelin/SafeCast.sol`: OpenZeppelin Contracts v5.0.2 (MIT), checked narrowing conversions used by RISC Zero. Original header preserved.
- Production DCAP program: [datachainlab/zkdcap](https://github.com/datachainlab/zkdcap/tree/fe39b99e976a9dc0e8d7232f0056b31eb81db7b1), Apache-2.0. Guest source and checked-in binary identify image `65ca60d4fce9aed394c4363c4cc550e781995c296eefe9f93858689078ccf82e`. Verify reproducible build before approving a release. Source checks quote/PCK/QE signatures, certificate constraints, signed CRLs/revocations, TCB/QE identities and validity intersection; outputs the trusted-root certificate hash and minimum TCB evaluation number, which our contract checks independently.
- `test/fixtures/TestReceiptV3_0.sol`: official RISC Zero v3.0.1 positive cryptographic receipt (Apache-2.0). It is **not a hardware quote**.
- `test/fixtures/ArchivedAutomataDcapReceipt.sol`: published [Automata DCAP](https://github.com/automata-network/automata-dcap-attestation/blob/41aedff9e95d6736f6feb8529d005b54b4fb3c42/evm/forge-test/zk/AutomataDcapZkTest.t.sol) proof/journal fixture (MIT). Its old program ID, stale collateral and non-OK TCB make it unsuitable for production. Tests authenticate its Groth16 proof then ensure the production verifier rejects it. Automata PCCS deployments, fees and collateral oracles are **not** adopted.

The Intel root DER was fetched from [Intel's certificate endpoint](https://certificates.trustedservices.intel.com/Intel_SGX_Provisioning_Certification_RootCA.cer) and compared byte-for-byte with zkDCAP's reference. Its keccak256 is `a1acc73eb45794fa1734f14d882e91925b6006f79d3bb2460df9d01b333d7009`. Do not replace it with a provider-supplied certificate.

OAuth research inspected [OmniRoute](https://github.com/diegosouzapw/OmniRoute) at commit `7510677f2f8f5317f1947284dab650d01333915d` (MIT, copyright 2026 diegosouzapw). No source code was copied. Our independent connector follows current official OpenAI token-sharing documentation instead of borrowed CLI client identities/backend endpoints; Anthropic's official third-party policy leaves Claude OAuth unavailable for this app. See [ACCOUNT_CONNECTORS.md](ACCOUNT_CONNECTORS.md) for primary references and unavailable usage modes.
